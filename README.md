# Sites de Emprego

Este é um projeto simples e funcional que centraliza os principais portais de carreira e busca de empregos, tanto nacionais (Brasil) quanto internacionais. O objetivo é facilitar o acesso rápido às plataformas de recrutamento.

## 🚀 Funcionalidades

- **Listagem Curada**: Acesso direto a sites como LinkedIn, Gupy, Vagas.com, Glassdoor e outros.
- **Categorização**: Divisão clara entre sites nacionais e internacionais.
- **Modo Escuro (Dark Mode)**: Suporte para alternância de tema para melhor conforto visual.
- **Interface Responsiva**: Design adaptável para diferentes tamanhos de tela.

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estruturação semântica do conteúdo.
- **CSS3**: Estilização e layout (arquivo `styles.css`).
- **JavaScript**: Lógica para alternância de tema (arquivo `script.js`).

## 📁 Estrutura do Projeto

```text
empregos/
├── index.html    # Página principal
├── styles.css    # Estilos e variáveis de cores
└── script.js    # Lógica do botão de tema
```

## 🔧 Como usar

1. Clone o repositório ou baixe os arquivos.
2. Abra o arquivo `index.html` em qualquer navegador moderno.
3. Utilize o botão "Modo Escuro" no topo da página para alternar o tema.
